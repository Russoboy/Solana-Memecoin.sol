# Solana-Memecoin.sol
Memecoin built on Solana using solidity

Features:
✅ Uses OpenZeppelin's ERC-20 implementation
✅ Mints 1 million tokens to the deployer initially
✅ Mint function (only owner can mint more tokens)
✅ Burn function (anyone can burn their tokens)

🛠 Deployment Steps:
Install Remix IDE
Paste the code & compile with Solidity 0.8.19+
Deploy using Injected Web3 (e.g., MetaMask)
Verify on Etherscan/BSCScan
